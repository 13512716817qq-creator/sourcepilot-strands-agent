# 晋导 2026 · 山西英语导游考试题库（增强版 v2.0）

本产品为适配 iPhone Safari 的原创离线 Web App / PWA。它**不是文化和旅游部、山西省文旅厅发布的官方真题**；2026 年 11 月 21 日考试尚未举行，完整考试试题不可能提前作为真题获取。

## 题库规模（2026-10-10）

- 笔试原创模拟 **1,101 道**：政策法规 213、导游业务 234、全国导游基础知识 300、山西地方导游基础知识 354。
- 口试原创训练 **172 项**：云冈石窟、五台山、平遥古城、洪洞大槐树、晋祠，山西专题，中英双向口译与服务应变。
- 这 1,101 道笔试题含**364 个新增知识点的单选与判断变式及综合辨析题**，不是 1,101 个不重复知识点、不是 1,101 道官方原题；题量统计包含变式复练。
- 原题库的 284 道保留原有题号与本地做题记录。

## App 核心功能

- 手机端分类、专题、题型、关键词搜索和逐题目录；每日20题、练习数量自选。
- 2026 笔试合卷 **模拟卷一**（法规+业务）、**模拟卷二**（全国基础+山西基础），每卷 165 题、90 分钟、100 分，题型比例严格按2026官方大纲：判断40×0.5、单选90×0.5、多选35×1。
- 口试：172 项英语景点讲解、专题讲解、情境问答和双向口译；语音朗读、倒计时，浏览器支持时录音。
- 错题本、收藏夹、复练、学习统计，导入/导出 JSON 备份。
- 记录存在当前设备的浏览器 localStorage，无云同步。清理浏览器数据前请导出备份。正式离线使用需 HTTPS 访问并完成初次缓存。

## 目录与学习资料

- `index.html` 页面入口，`app.js` 业务逻辑，`styles.css` 页面样式。
- `bank-01.js` ~ `bank-14.js` 可直接加载的全部 1101 道题目。
- `oral-data.js` 所有 172 道英语口试练习。
- `完整笔试题库_2026_原创模拟.json`：可读、可导入数据库的完整题目、选项、正确答案索引、解析和科目分类。
- `完整英语口试题库_2026_原创训练.json`：全部英语口试练习及参考回答。
- `manifest.webmanifest`, `sw.js`, `icons/`：支持添加到 iPhone 主屏幕。

## 安装到 iPhone

1. 将 App 文件夹的全部静态文件上传到支持 HTTPS 的托管平台（Cloudflare Pages / Render static site 等），或使用已配置的 GitHub Pages 测试地址。
2. iPhone Safari 打开你自己的 HTTPS 链接。
3. 点击 **分享 → 添加到主屏幕 → 添加**。打开桌面图标练习。
4. 安装/升级 App 后，如看到旧题量，关闭主屏幕 App 并重新联网打开一次，让新 Service Worker 缓存生效。
