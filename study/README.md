# 晋导 · 2026 山西英语导游备考 App

移动优先的离线 PWA。非官方产品；全部选择、判断、多选为 **284 道原创模拟题**，另有 **67 个英语口试任务**（景点、专题、口译与服务情景）。2026 年的完整试题尚未公开，本 App 不能替代官方原题、当年口试大纲或认证教材。

## 内容

- 笔试四科：《政策与法律法规》《导游业务》《全国导游基础知识》《地方导游基础知识》
- 每张正式笔试卷：40 道判断 / 90 道单选 / 35 道多选，共 165 道 / 100 分 / 90 分钟（官方 2026 大纲）。
- 165 题模考：本练习是**四科混合**的题型结构仿真，并非一张真实合卷。两个分卷另提供 40 题专项训练。
- 口试：参照 2025 山西英语类大纲的五个景区及三个专题，用原创英语任务练习；2026 当地现场考试的最终范围须以山西省文旅厅公布为准。
- 每日 20 题、分类筛选、单/多/判断、已练/未做/错题/收藏、判题解析、学习统计、备份与恢复。
- 口试倒计时、参考讲解、浏览器 TTS、在支持且授权的 HTTPS 浏览器中录音。
- 数据存在当前浏览器的 localStorage；**不云同步，不上传录音**。离线功能在 HTTPS 完成首次缓存后生效。

## 如何给 iPhone 用

1. 将整个文件夹部署到 HTTPS 静态托管（Cloudflare Pages、Render 静态网站等），不要仅打开 ZIP 当成 iPhone 原生应用。
2. iPhone **Safari** 访问公开 HTTPS 网址。
3. 点「分享」→「添加到主屏幕」→「添加」。
4. 首次联网载入后可缓存离线使用。不同设备间请用「我的 → 导出 / 导入」迁移记录。

本仓库包含 `index.html`, `styles.css`, `app.js`, `data.js`, `manifest.webmanifest`, `sw.js`, `icons/`，不需要打包构建步骤；将根目录直接作为发布目录即可。
